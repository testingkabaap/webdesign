Image folder structure for your Laravel project (public/assets/img/):

assets/img/hero/hero-main.jpg              -> Homepage hero background image
assets/img/about/about-main.jpg            -> About section big image
assets/img/about/about-secondary.jpg       -> About section small image
assets/img/projects/project-1.jpg          -> SMD Golden Residency
assets/img/projects/project-2.jpg          -> SMD Royal Greens
assets/img/projects/project-3.jpg          -> SMD Elite Farms
assets/img/projects/project-4.jpg          -> SMD Green Valley
assets/img/projects/project-5.jpg          -> SMD Imperial Township
assets/img/gallery/gallery-1.jpg  ... gallery-8.jpg  -> Gallery section (8 photos)
assets/img/logo/SMD-Logos-6-251x300.webp   -> already referenced in nav (existing)

Just drop your photos into these exact filenames/paths and they'll show up automatically.
Recommended sizes: hero ~1200x1400px, about ~800x700 & 600x500, project cards ~800x600, gallery ~800-1000px wide.
